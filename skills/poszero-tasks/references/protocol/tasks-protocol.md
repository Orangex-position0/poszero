# Tasks Protocol

- Lite returns the `change.md` execution scope without creating `tasks.md`.
- Standard uses functional batches, ordered tasks, completion conditions, and verification commands.
- Deep may use full `REQ-*` → `SC-*` → `TASK-*` coverage, dependency graphs, and Ready analysis.
- Generate an Execution Packet for Implement. Keep it scoped to the current batch or slice.
