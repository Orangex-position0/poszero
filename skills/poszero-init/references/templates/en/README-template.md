This directory stores PosZero project contracts.

- Suite Version: {{SUITE_VERSION}}
- Template Version: {{TEMPLATE_VERSION}}
- Document Language: en | zh-CN

## Layout

- `constitution.md`: project-wide long-lived constraints.
- `templates/`: document templates for new features.
- `<feature-slug>/`: one feature contract; Standard / Deep use `spec.md`, `plan.md`, `tasks.md`, and `validation.md`, while Lite uses `change.md`.

Update templates by review. Do not overwrite project customizations without approval.
